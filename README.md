Студент: Монастирський Артем Юрійович. Група: КН-31. Викладач: Дупак Богдан Петрович.

Відкрийте index.html, щоб обрати роботу. Кожна лабораторна містить окремі HTML/CSS/JS файли відповідно до методички та README із запуском і поясненням граничних випадків. Bootstrap і jQuery включені локально.

Папки локального комплекту: «Лабораторні роботи» — вихідні файли; «Архіви» — дев’ять ZIP для здачі; «Звіти» — дев’ять Word-звітів; «Перевірка» — відтворювані програмні перевірки. Методички не змінювалися.

Репозиторій: https://github.com/Lemo95113/internet-technologies-labs

## Перевірка коду

Потрібен Node.js 18 або новіший, додаткові npm-пакети не потрібні:

```text
node Перевірка/test-labs.cjs
```

108 програмних перевірок охоплюють синтаксис, локальні посилання, рівняння, конвертацію, контролери діалогів, усі гілки гри, функції масивів, ООП та наслідування. Сценарії confirm/prompt перевіряються контрольованими відповідями; це не твердження про автоматизовану роботу нативного інтерфейсу браузерних діалогів.

Локальний сервер за потреби:

```text
node Перевірка/serve.cjs
```

Адреса: http://127.0.0.1:8767 . Для зупинки сервера натисніть Ctrl+C у його терміналі. Звичайний запуск HTML-файлів не потребує сервера.

У GitHub розміщено вихідний код, бібліотеки та програмні перевірки. Word-звіти, ZIP, методички й скріншоти залишаються в локальній папці предмета.
