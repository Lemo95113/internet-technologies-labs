# Лабораторна робота 7 — Наслідування

Монастирський Артем Юрійович, КН-31. Викладач: Дупак Богдан Петрович.

## Запуск

Відкрийте `index.html` у сучасному браузері. Для робіт №2, №3 та №9 кожне завдання міститься в окремому taskN.html. Усі бібліотеки й ресурси включені до папки, встановлення пакетів не потрібне. Для справжньої консолі відкрийте DevTools → Console (F12); результати додатково дублюються в блоці сторінки.

## Реалізація

Прототипи Student і Teacher створено через Object.create(Human.prototype), constructor відновлено. Human має sleep і describe, Student — goToUniversity, Teacher перевизначає describe. Усі методи викликано у сценарії. Дані навчальних персонажів не є біографічними даними студента або викладача.

## Перевірка

Для цієї роботи пройдено 10 програмних перевірок у загальному Node.js стенді. Окремі браузерні перевірки та скріншоти збережено у results. Скрипт усіх перевірок — у папці «Перевірка» предмета або в репозиторії. Повний код доступний у цьому ZIP; звіт Word — у папці «Звіти» предмета.
