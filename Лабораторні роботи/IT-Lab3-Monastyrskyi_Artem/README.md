## Запуск

Відкрийте `task1.html` у сучасному браузері. Для робіт №2, №3 та №9 кожне завдання міститься в окремому taskN.html. Усі бібліотеки й ресурси включені до папки, встановлення пакетів не потрібне. Для справжньої консолі відкрийте DevTools → Console (F12); результати додатково дублюються в блоці сторінки.

## Реалізація

Шаховий візерунок 8×8 створено тільки циклами while та змінними sh і sp. Гра використовує confirm, prompt і Math.random; призи 10/5/2, подвоєння максимуму 5→10→20, потроєння призів і накопичення виграшу. Програш скидає виграш до нуля; повторна гра починається з початкових умов. Некоректний ввід не витрачає спробу, Cancel завершує гру. Усі гроші умовні.

## Перевірка

Для цієї роботи пройдено 12 програмних перевірок у загальному Node.js стенді. Окремі браузерні перевірки та скріншоти збережено у results. Скрипт усіх перевірок — у папці «Перевірка» предмета або в репозиторії. Повний код доступний у цьому ZIP; звіт Word — у папці «Звіти» предмета.
