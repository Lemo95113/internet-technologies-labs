Монастирський Артем Юрійович, КН-31. Викладач: Дупак Богдан Петрович.

## Запуск

Відкрийте `index.html` у сучасному браузері. Для робіт №2, №3 та №9 кожне завдання міститься в окремому taskN.html. Усі бібліотеки й ресурси включені до папки, встановлення пакетів не потрібне. Для справжньої консолі відкрийте DevTools → Console (F12); результати додатково дублюються в блоці сторінки.

## Реалізація

getFullName використовує деструктуризацію й шаблонний рядок. handleThings(opts = {}) зберігає поведінку вихідного прикладу для опційного об’єкта: замінює name та повертає той самий об’єкт. Для явного null вихідний приклад мав додаткову нормалізацію через ||, тоді як параметр за замовчуванням призначений для undefined або пропущеного аргументу. Queue копіює переданий iterable через spread і реалізує FIFO методом shift; порожня черга повертає undefined.

## Перевірка

Для цієї роботи пройдено 9 програмних перевірок у загальному Node.js стенді. Окремі браузерні перевірки та скріншоти збережено у results. Скрипт усіх перевірок — у папці «Перевірка» предмета або в репозиторії. Повний код доступний у цьому ZIP; звіт Word — у папці «Звіти» предмета.
