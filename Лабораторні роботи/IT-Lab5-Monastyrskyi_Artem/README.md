## Запуск

Відкрийте `index.html` у сучасному браузері. Для робіт №2, №3 та №9 кожне завдання міститься в окремому taskN.html. Усі бібліотеки й ресурси включені до папки, встановлення пакетів не потрібне. Для справжньої консолі відкрийте DevTools → Console (F12); результати додатково дублюються в блоці сторінки.

## Реалізація

Реалізовано п’ять функцій з тексту завдання. У структурі методички також названо getTopNRichestNames.js без окремої умови: додано функцію getTopNRichestNames(people, count) для записів {name, balance}, яка повертає імена N найбагатших без зміни вхідного масиву. Зворотне шифрування очікує однозначну посимвольну карту; перетворення як у методичці не може відновити символи, якщо вихідні дані містять незамінені символи, що збігаються з кодовими значеннями.
