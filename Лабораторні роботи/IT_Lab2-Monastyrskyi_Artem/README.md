## Запуск

Відкрийте `task1.html` у сучасному браузері. Для робіт №2, №3 та №9 кожне завдання міститься в окремому taskN.html. Усі бібліотеки й ресурси включені до папки, встановлення пакетів не потрібне. Для справжньої консолі відкрийте DevTools → Console (F12); результати додатково дублюються в блоці сторінки.

## Реалізація

Основний ввід виконується через prompt, результат рівняння — через console.log, конвертація — через alert. Додаткова кнопка навчального прикладу викликає ті самі обчислювальні функції з контрольними даними без діалогів. Курси НБУ на 19.11.2026: USD 45.202, EUR 49.5717. Знімок API міститься у data/nbu-2026-11-19.json. Дата курсу фіксована відповідно до дати виконання; комісії не враховуються.

## Перевірка

Для цієї роботи пройдено 20 програмних перевірок у загальному Node.js стенді. Окремі браузерні перевірки та скріншоти збережено у results. Скрипт усіх перевірок — у папці «Перевірка» предмета або в репозиторії. Повний код доступний у цьому ZIP; звіт Word — у папці «Звіти» предмета.
