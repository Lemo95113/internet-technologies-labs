## Запуск

Відкрийте `task1.html` у сучасному браузері. Для робіт №2, №3 та №9 кожне завдання міститься в окремому taskN.html. Усі бібліотеки й ресурси включені до папки, встановлення пакетів не потрібне. Для справжньої консолі відкрийте DevTools → Console (F12); результати додатково дублюються в блоці сторінки.

## Реалізація

jQuery 3.7.1 підключено локально до кожної сторінки. script1 — click для field1; script2 — click і dblclick початкового параграфа; script3 — делегований click із назвою event.target.tagName, один alert на дію. Подвійний клік браузера також породжує звичайні click-події, тому можливі додаткові click-параграфи — це стандартна модель подій.

## Перевірка

Для цієї роботи пройдено 3 програмних перевірок у загальному Node.js стенді. Окремі браузерні перевірки та скріншоти збережено у results. Скрипт усіх перевірок — у папці «Перевірка» предмета або в репозиторії. Повний код доступний у цьому ZIP; звіт Word — у папці «Звіти» предмета.
