# Лабораторна робота 4 — Функції JavaScript

Монастирський Артем Юрійович, КН-31. Викладач: Дупак Богдан Петрович.

## Запуск

Відкрийте `index.html` у сучасному браузері. Для робіт №2, №3 та №9 кожне завдання міститься в окремому taskN.html. Усі бібліотеки й ресурси включені до папки, встановлення пакетів не потрібне. Для справжньої консолі відкрийте DevTools → Console (F12); результати додатково дублюються в блоці сторінки.

## Реалізація

У тексті завдань описано чотири функції. Структура методички додатково вимагає isPrime.js і guessingGame.js, тому вони також реалізовані: перевірка простоти та гра з попередньої роботи. getMin і getClosestToZero відхиляють порожній список; за рівної відстані до нуля повертається перший аргумент. Репозиторій: https://github.com/Lemo95113/internet-technologies-labs/tree/main/Лабораторні%20роботи/IT-Lab4-Monastyrskyi_Artem

## Перевірка

Для цієї роботи пройдено 20 програмних перевірок у загальному Node.js стенді. Окремі браузерні перевірки та скріншоти збережено у results. Скрипт усіх перевірок — у папці «Перевірка» предмета або в репозиторії. Повний код доступний у цьому ZIP; звіт Word — у папці «Звіти» предмета.
