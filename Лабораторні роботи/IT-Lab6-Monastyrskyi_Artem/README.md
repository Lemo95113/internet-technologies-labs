Монастирський Артем Юрійович, КН-31. Викладач: Дупак Богдан Петрович.

## Запуск

Відкрийте `index.html` у сучасному браузері. Для робіт №2, №3 та №9 кожне завдання міститься в окремому taskN.html. Усі бібліотеки й ресурси включені до папки, встановлення пакетів не потрібне. Для справжньої консолі відкрийте DevTools → Console (F12); результати додатково дублюються в блоці сторінки.

## Реалізація

SlotMachine і Casino реалізовано функціями-конструкторами з інкапсуляцією через замикання. Публічні методи: getMoney, takeMoney, putMoney; getTotalMoney, getMachineCount, getMachines, addSlotMachine, removeSlotMachine. Початкова сума ділиться порівну, видалення перерозподіляє баланс. Останню машину видалити не можна. ID унікальні та незмінні. Це навчальна модель з умовними одиницями; дробові обчислення JavaScript перевіряються з числовим допуском.

## Перевірка

Для цієї роботи пройдено 16 програмних перевірок у загальному Node.js стенді. Окремі браузерні перевірки та скріншоти збережено у results. Скрипт усіх перевірок — у папці «Перевірка» предмета або в репозиторії. Повний код доступний у цьому ZIP; звіт Word — у папці «Звіти» предмета.
